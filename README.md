# Kanglon Educational Website

A responsive, mobile-friendly educational website for Classes 7–10.

## Structure
- `index.html` — website structure
- `styles.css` — responsive design
- `script.js` — class → subject → chapter → PDF selection
- `pdfs/` — place your actual PDF files here

## Adding PDFs
The JavaScript expects files in this format:

`pdfs/class-7/mathematics/integers.pdf`

For example:
- `pdfs/class-8/science/force-and-pressure.pdf`
- `pdfs/class-10/mathematics/trigonometry.pdf`

Update the chapter names in `script.js` and put matching PDF files in the corresponding folders.

## Publishing on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save. GitHub will publish the site.

Replace the placeholder contact details and the text in the About Me section before publishing.
